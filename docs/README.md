# Юридические документы

Созданы две обязательные страницы:

- `privacy-policy.html` — политика обработки персональных данных.
- `personal-data-consent.html` — согласие на обработку персональных данных.

Перед публикацией заполните все TODO-плейсхолдеры оператора:

- `[УКАЗАТЬ ПОЛНОЕ НАИМЕНОВАНИЕ ОПЕРАТОРА]`
- `[УКАЗАТЬ ИНН]`
- `[УКАЗАТЬ ОГРН/ОГРНИП]`
- `[УКАЗАТЬ ЮРИДИЧЕСКИЙ АДРЕС]`
- `[УКАЗАТЬ EMAIL ДЛЯ ОБРАЩЕНИЙ ПО ПД]`
- `[УКАЗАТЬ ДАТУ РЕДАКЦИИ ДОКУМЕНТА]`

Тексты являются рабочим шаблоном и не заменяют юридическую проверку.
