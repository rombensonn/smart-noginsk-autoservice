# Изображения

`service-map.svg` — лёгкая векторная иллюстрация концепции «сервисная карта автомобиля».

Если появятся реальные фотографии сервиса, боксов, зоны ожидания или мастеров, их лучше добавить сюда в WebP/AVIF и заменить hero-иллюстрацию на реальные фото. Перед публикацией сжимайте изображения и указывайте `width`, `height`, `loading="lazy"` для контента ниже первого экрана.
